I want to start a new feature using the structured workflow.

Please help me:

1. **Ask me for the feature name** (e.g., "rate-limiting", "confluence-adapter")

2. **Create a new feature branch**:
   - Ensure main is up to date
   - Create branch: `feature/<feature-name>`
   - Verify the branch was created

3. **Create requirements document**:
   - Copy `docs/requirements/TEMPLATE.md` to `docs/requirements/<feature-name>.md`
   - Open the requirements document and show me the Quick Reference section
   - Ask me to fill in the objective and key requirements

4. **Set expectations**:
   - Tell me we'll work in plan mode once requirements are ready
   - Remind me to fill in at least these sections:
     - Objective (section 1)
     - Must Have requirements (section 3.1)
     - Technical Constraints (section 6)
     - Success Criteria (section 10)

Do NOT create any implementation code yet. This is just the setup phase.

After the requirements file is created, ask me:
"Would you like to fill in the requirements now, or would you like me to help draft them based on a description you provide?"
